# E-mail no automaster — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** trazer os templates do email builder para o dump, provar se template ausente da lista é template apagado, e entregar duas regras de auditoria de e-mail mais uma tool MCP de leitura.

**Architecture:** o extractor varre `GET backend/emails/builder` (raiz mais pastas, recursivo) e grava `email_templates.json`. O auditor cruza cada step de e-mail com essa lista pelo id embutido no `previewUrl` — nunca pelo `template_id`, que é cópia interna do step. A tool `modelos_email` lê o dump e, só na operação `conteudo`, baixa o HTML de uma URL pública sem token.

**Tech Stack:** TypeScript + Playwright (extractor), Python 3.12 + pytest (auditor), MCP stdio.

**Spec:** `docs/superpowers/specs/2026-09-20-emails-design.md`
**Dossiê:** `docs/superpowers/research/2026-09-20-emails-research.md`

## Global Constraints

- `schemaVersion` do dump continua **1**. Arquivo opcional novo é aditivo; incrementar invalidaria os 12 dumps em disco.
- O `raw` do dump nunca é transformado nem limpo. `email_templates.json` guarda `{fetchedAt, raw: {builders: [...]}}`.
- Nenhuma escrita ao vivo neste plano. Nenhuma operação manda e-mail.
- Escrita ao vivo é serial: nunca dois comandos que abrem Chrome ao mesmo tempo. Vale para `npm run extract`.
- Subconta de validação: `Xb9gDxwxYhdqtprGcb5E` (Instaltech). Segunda subconta com steps de e-mail: `citQs4acsN1StzOEDuvj` (Cliente B).
- Nome da tool MCP: `modelos_email`. Nomes de regra: `stale_email_template` (WARN) e `unused_email_template` (INFO).
- Rotas v3 (`/emails/locations/<loc>/templates`) estão fora: respondem `404 Cannot GET` com os tokens da sessão.
- Testes antes do código, commit por tarefa. Auditor: `.venv/bin/python -m pytest -q`. Extractor: `npx tsc --noEmit` e `npm test`.

```ts
import type { GhlClient } from "./client.js";

/**
 * Templates do email builder da subconta. Host `backend.leadconnectorhq.com`,
 * dois tokens da sessão. A lista vem uma pasta por vez: item com
 * `templateType: "folder"` esconde os seus, que só aparecem passando
 * `parentId=<id da pasta>`.
 * Rotas em docs/endpoints.md, seção `## Templates de e-mail`.
 */
const BACKEND = "https://backend.leadconnectorhq.com";

/** O default do servidor é 25; este valor cobre subconta grande sem paginar à toa. */
const PAGINA = 100;

type Item = Record<string, unknown> & { id?: string; templateType?: string };

/** Varre a raiz e desce em cada pasta. `buscar` recebe o parentId (undefined = raiz). */
export async function achatarPastas(
  buscar: (parentId?: string) => Promise<unknown[]>,
): Promise<unknown[]> {
  const vistos = new Set<string>();
  const saida: unknown[] = [];

  const descer = async (parentId?: string): Promise<void> => {
    const itens = (await buscar(parentId)) as Item[];
    const pastas: string[] = [];
    for (const it of itens) {
      const id = String(it.id ?? "");
      if (!id || vistos.has(id)) continue;  // pasta que se referencia não vira loop
      vistos.add(id);
      saida.push(it);
      if (it.templateType === "folder") pastas.push(id);
    }
    for (const p of pastas) await descer(p);
  };

  await descer(undefined);
  return saida;
}

/** Uma página por vez da rota, já paginada por offset. */
async function paginar(client: GhlClient, locationId: string, parentId?: string): Promise<unknown[]> {
  const itens: unknown[] = [];
  for (let offset = 0; ; offset += PAGINA) {
    const q = new URLSearchParams({ locationId, limit: String(PAGINA), offset: String(offset) });
    if (parentId) q.set("parentId", parentId);
    const resp = await client.getJson<{ builders?: unknown[] }>(`${BACKEND}/emails/builder?${q}`);
    const pagina = resp.builders ?? [];
    itens.push(...pagina);
    if (pagina.length < PAGINA) break;
  }
  return itens;
}

/** Todos os templates e pastas do email builder, achatados. */
export async function fetchEmailTemplates(
  client: GhlClient, locationId: string,
): Promise<{ builders: unknown[] }> {
  const builders = await achatarPastas((parentId) => paginar(client, locationId, parentId));
  return { builders };
}
```

```python
_PREVIEW_ID = re.compile(r"emails/([^/]+)/index\.html")


def email_template_id(step: dict) -> str:
    """Id do template de e-mail citado por um step, ou string vazia se não der para saber."""
    attrs = step.get("attributes") or {}
    url = unquote(str(attrs.get("previewUrl") or ""))
    m = _PREVIEW_ID.search(url)
    return m.group(1) if m else ""
```

- [ ] **Step 3: Write the rule**

```python
"""WARN: step de e-mail apontando para um template que não está mais no email builder.

É WARN e não ERROR porque o e-mail continua sendo enviado: o conteúdo renderizado vive no
Storage, e foi medido ao vivo respondendo 200 mesmo para os ids ausentes da lista. O que se
perdeu é a possibilidade de editar aquele e-mail pelo app — quem abrir o template de mesmo
nome no builder estará mexendo em outro registro.

O id vem do `previewUrl`, nunca do `template_id`: quando o usuário escolhe um template
existente, o GHL guarda uma cópia dentro do step e o `template_id` passa a ser o dessa
cópia, que por construção não aparece na lista do builder.
"""
from __future__ import annotations

from ..finding import WARN, Finding
from ..loader import DumpContext
from ._helpers import email_template_id, steps_of_type


def check(ctx: DumpContext) -> list[Finding]:
    conhecidos = ctx.template_ids.get("email")
    if not conhecidos:  # lista ausente ou vazia: nada a cruzar
        return []
    findings: list[Finding] = []
    for wf, step in steps_of_type(ctx, "email"):
        tid = email_template_id(step)
        if not tid or tid in conhecidos:
            continue
        assunto = (step.get("attributes") or {}).get("subject") or ""
        findings.append(
            Finding(
                rule="stale_email_template",
                severity=WARN,
                workflow_id=wf.id,
                workflow_name=wf.name,
                detail=f"step '{step.get('name', step.get('type'))}' (assunto {assunto!r}) usa "
                       f"template de e-mail que não está mais no builder: {tid} — o e-mail "
                       f"ainda é enviado, mas não dá para editá-lo pelo app",
            )
        )
    return findings
```

```python
"""INFO: template de e-mail que existe no builder e nenhum workflow usa.

É INFO, nunca ERROR: um template pode ser usado em campanha de e-mail, disparo manual ou
outra parte do CRM que o dump não enxerga. O achado serve para revisão humana.
"""
from __future__ import annotations

from ..finding import INFO, Finding
from ..loader import DumpContext
from ._helpers import email_template_id, steps_of_type


def check(ctx: DumpContext) -> list[Finding]:
    conhecidos = ctx.template_ids.get("email")
    if not conhecidos:  # lista ausente ou vazia: nada a apontar
        return []
    usados = {email_template_id(step) for _, step in steps_of_type(ctx, "email")}
    findings: list[Finding] = []
    for tid in sorted(conhecidos - usados):
        findings.append(
            Finding(
                rule="unused_email_template",
                severity=INFO,
                workflow_id="",
                workflow_name="",
                detail=f"template de e-mail '{ctx.template_names.get(tid, tid)}' não é usado por "
                       f"nenhum workflow — pode estar em campanha ou disparo manual, que o dump "
                       f"não enxerga",
            )
        )
    return findings
```

```python
def _ler_url(url: str) -> bytes:
    """Isolada para o teste trocar. Única ida à rede do servidor: URL pública, sem credencial."""
    with urlopen(Request(url, headers={"user-agent": _UA}), timeout=20) as r:  # noqa: S310
        return r.read()


class _Texto(HTMLParser):
    """Texto visível e hrefs de um HTML de e-mail; o markup inteiro é grande demais."""

    def __init__(self) -> None:
        super().__init__()
        self.partes: list[str] = []
        self.links: list[str] = []
        self._pular = False

    def handle_starttag(self, tag, attrs):
        if tag in ("script", "style"):
            self._pular = True
        if tag == "a":
            href = dict(attrs).get("href")
            if href:
                self.links.append(href)

    def handle_endtag(self, tag):
        if tag in ("script", "style"):
            self._pular = False

    def handle_data(self, data):
        if not self._pular and data.strip():
            self.partes.append(data.strip())


def modelos_email(loc: str, o: str = "lista", id: str | None = None,
                  snapshot: str | None = None) -> dict:
    if o not in MODELOS_OP:
        raise ToolError(f"operação {o!r} inválida; use uma de {MODELOS_OP}")
    ctx, meta = _load(loc, snapshot)

    if o == "lista":
        modelos = [
            {"id": str(b.get("id")), "nome": b.get("name"), "pasta": b.get("parentId"),
             "criado": b.get("dateAdded"), "alterado": b.get("lastUpdated"),
             "texto_puro": b.get("isPlainText")}
            for b in ctx.email_templates
        ]
        return {"modelos": modelos, "_snapshot": meta}

    if o == "usos":
        usos: dict[str, list[dict]] = {}
        for wf, step in steps_of_type(ctx, "email"):
            tid = email_template_id(step)
            if not tid:
                continue
            usos.setdefault(tid, []).append({
                "workflow": wf.name, "step": step.get("name", step.get("type")),
                "assunto": (step.get("attributes") or {}).get("subject", ""),
            })
        conhecidos = {str(b.get("id")) for b in ctx.email_templates}
        return {"usos": usos, "sem_uso": sorted(conhecidos - set(usos)),
                "fora_do_builder": sorted(set(usos) - conhecidos), "_snapshot": meta}

    if not id:
        raise ToolError("conteudo exige `id`; pegue um com a operação `lista` ou `usos`")
    location_id = ctx.manifest.get("locationId", loc)
    bruto = _ler_url(_EMAIL_URL.format(loc=location_id, tid=id))
    p = _Texto()
    p.feed(bruto.decode("utf-8", "replace"))
    return {"id": id, "texto": "\n".join(p.partes), "links": p.links, "_snapshot": meta}
```
